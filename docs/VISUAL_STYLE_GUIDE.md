# VISUAL STYLE GUIDE — O Último Rastro

Identidade: **gótico sombrio · emocional · cinematográfico · estranho · narrativo**  
Linguagem: conto sombrio + animação 2D estilizada + horror psicológico + investigação

---

## 1. Princípios

1. **Inocência × horror** — Theo é pequeno; o mundo é grande e hostil.
2. **Silhuetas alongadas** — trolls e sombras; proporções adultas ligeiramente caricaturais.
3. **Olhos comunicativos** — maior vetor emocional; brilho mínimo e seletivo.
4. **Linhas orgânicas imperfeitas** — traço à mão, nunca CAD perfeito.
5. **Preto profundo + destaques frios** — poucos pontos de cor saturada.
6. **Composição cinematográfica** — regra dos terços, negative space, luz volumétrica.

## 2. Paleta

| Papel | Cor | Uso |
|---|---|---|
| Base | `#0A0B10` | fundo, sombra profunda |
| Painel | `#12121A` | UI, interiors |
| Neutro frio | `#3A3F4C` | pedra, metal envelhecido |
| Neutro claro | `#8A919E` | texto secundário, névoa |
| Carne Theo | `#C4A484` | pele (dessaturada) |
| Destaque frio | `#6EC1E4` | magia, Orun, véu |
| Destaque quente | `#C45C48` | perigo, erro, tensão (uso raro) |
| Corvo/negro | `#1A1A22` | silhuetas |
| Dourado velho | `#B8956A` | documentos, memória |
| Verde troll | `#4A6B4F` | pele trolls (dessaturado) |

Regra: **no máximo 1 destaque saturado por quadro.**

## 3. Personagens — regras gerais

- Cabeça levemente maior que anatomia realista (8–9 cabeças no total para adultos; Theo ~6).
- Olhos grandes, íris clara; trolls: pupilas verticais ou brilho amarelo/verde.
- Cabelo orgânico em blocos, nunca fios individuais perfeitos.
- Roupas em tecidos pesados, sombras em V, bordas desgastadas.
- Contorno: preto `#000` a `#1A1A1A`, espessura variável.

## 4. Theo (ficha)

| Atributo | Especificação |
|---|---|
| Idade | 10–12 |
| Altura | ~6 cabeças |
| Cabelo | escuro, bagunçado, franja sobre testa |
| Olhos | grandes, castanho-claro; medo→brilho excessivo |
| Roupa | casaco azul-acinzentado gasto, calça escura, tênis |
| Silhueta | cabeça grande, ombros estreitos, mochila |
| Expressões base | neutro, investigando (pálpebras baixas), assustado (olhos arregalados), triste (sobrancelhas internas altas), determinado (sobrancelhas baixas) |

### Transformação (progressiva)
0 — baseline  
1 — olheiras, pele um pouco mais pálida  
2 — veias sutis, olhos mais brilhantes, sombra alongada  
3 — mandíbula sutil, mãos maiores, pele acinzentada  
4 — troll completo (escala, pupilas, proporção)

## 5. Clara (mãe)
- Adulta, cabelo longo escuro, casaco/manto  
- Expressões: normal, preocupada, assustada, desespero  
- Silhueta suave, linhas curvas (contraste com trolls)

## 6. Elias (pai)
- Adulto alto, cabelo curto, sobrancelha marcada  
- Roupa casual escura  
- Expressões: normal, preocupado, assustado

## 7. Silas (chefe / troll disfarçado)
- Terno escuro, postura reta, sorriso contido  
- Disfarce: humano idoso elegante  
- Revelado: pele troll, olhos brilhantes, dentes, sombra alongada  
- Ameaçador: silhouette massiva, luz de baixo

## 8. Trolls
- Silhueta alongada, ombros altos, braços longos  
- Cabeça pequena ou chifres/surdinas orgânicas  
- Pele: verde-oliva dessaturado, textura rochosa  
- Olhos brilhantes (âmbar/verde)  
- Variações: mensageiro (fino), condutor (robusto), copista (hunch), ferreiro (braços grossos), guardião (grande)

## 9. Cenários
- Arquitetura decadente, umidade, fungos, rachaduras  
- Luz: um ponto dramático principal + fill frio  
- Profundidade: 3 planos (fore detalle, mid ação, far atmosfera)  
- Efeitos: névoa, poeira, chuva, god rays quando justificado  
- Câmera: 16:9, ponto de fuga deslocado, não centralizar sempre

## 10. Cubo de Orun
- Cubo de pedra/obsidiana fria, runas levemente gravadas  
- Símbolos em `#6EC1E4` quando ativos  
- Erro: flash `#C45C48` breve  
- Correto: glow progressivo  
- 6 faces: olho, lua, mao, corvo, arvore, rosto  
- Nunca texto alfabético nas faces (apenas glifos)

## 11. Interface
- Monospace atual preservada para legibilidade  
- Painéis: borda `#2A2A3A`, fundo `#12121A` 92%  
- Hover: branco; erro: `#C45C48`; acerto: `#88FF88`  
- Legendas: fundo preto 70%, texto claro, speaker em destaque frio

## 12. Finais
- **GOOD** — contraste frio, hélice leve, fundo escuro  
- **BAD** — vermelho residual, textura suja, sombra  
- **SECRET** — glow azul, profundidade, silêncio visual  

## 13. Proibido
- Copiar personagens/franquias existentes  
- Gore explícito  
- Texto localizado rasterizado em imagem  
- Estilos inconsistentes entre fases do mesmo ato
